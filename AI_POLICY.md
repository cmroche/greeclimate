# AI Policy

Using AI (LLMs) as tools for development is allowed. However, all contributions to this project are held to a high standard of quality, and contributors are expected to be responsible for any code or issues they submit.

AI may not be used to generate responses to questions in PRs, Issues, or other communications with human participants in the project, and project maintainers.

This project requires a human in the loop, that understands and can explain all changes made.

If you use wish to use AI to translate, include the original language text and put the translation in a block-quote.

Failure to follow this policy will result in PRs/Issue being closed or hidden, continued violations may result in a ban from the project.

AI is a usefull tool for development, but improper use results in an unmanageable workload for maintainers. Please be respectful of the time and effort put by others into managing this project.
