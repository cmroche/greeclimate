# Known HIDs

## String segments

Example: `362001066763+U-W06A(P3)V6.04.bin`, reported for Sinclair air-to-water units with MID `9300`:

| Segment | Meaning and limits |
| --- | --- |
| <a id="362001066763"></a><code>362001066763</code> | opaque firmware code, sent as <code>firmwareCode</code> to Gree's update API. Code lengths vary; no subfield decoding is verified. |
| <code>+</code> | separates the code from the firmware name; it is not part of the filename prefix. |
| <code>U-</code> | literal prefix with no verified expansion; some names omit it. |
| <code>W06A</code> | [INFERENCE] module/platform designation; individual characters are not decoded. <code>CS532AE(LT)</code> is independently documented as a Wi-Fi module name ([certification][module-certification]). |
| <code>(P3)</code> | [INFERENCE] variant qualifier, not proof of protocol version 3. Its expansion is unknown; <code>LT</code>, <code>MTK</code>, and <code>MTK2</code> need not mean the same thing. |
| <code>V6.04</code> | literal firmware-version string. Gree's separate <code>commProtVer</code> field is the communication protocol version. Do not compare versions across firmware families. |
| <code>.bin</code> | image-filename extension, not proof of executable content or a reported HID. |
